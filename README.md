 # Automobiles - Exploratory Data Analysis

Exploratory Data Analysis on 193 vehicles to understand the relationship between vehicle specs and pricing.

### Dataset
- 193 observations, 24 variables
- Features: make, body-style, fuel-type, engine-size, horsepower, city-mpg, highway-mpg, price

### What I Did
- Removed unnecessary columns (normalized-losses, symboling)
- Handled missing values marked as '?'
- Converted data types and checked for duplicates
- Created visualizations to analyze trends

### Key Findings
1. Most Expensive: Mercedes-Benz (R45,400), BMW, Porsche - luxury brands premium pricing
2. Engine Size vs Price: Positive correlation - bigger engines cost more
3. Body Style: 63 hatchbacks - high popularity segment
4. Fuel Efficiency varies significantly by manufacturer

### Tools
Python, Pandas, Matplotlib, Data Cleaning, EDA
